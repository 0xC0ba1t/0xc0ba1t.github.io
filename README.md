# c0ba1t — terminal-inspired portfolio

Next.js (App Router, static export) · TypeScript · Tailwind CSS v4 · Motion · Lucide.
Hosted on GitHub Pages at <https://c0ba1t.is-a.dev/>.

## Run it

```bash
npm install
npm run dev          # http://localhost:3000
npm run typecheck
npm run build        # static export -> ./out
npm run preview      # serve ./out locally
npm run assets       # regenerate public/og.png and public/images/dither-mask.png
```
